# Парсер Ростреестра
по кадастровым номерам определяет:
1) существование записи в Росреестре;
2) вид объекта недвижимости.
# Запуск
1. установка виртуального окружения
`python -m venv .venv`
2. активация
`.\.venv\Scripts\activate`
3. установить зависимости
`pip install -r requirements.txt`
4. добавить файл с кадастровыми номерами - `input.csv` в корне проекта
```csv
kadastral_number
11:22:3333333:444
11:22:333333:44
```
5. запустить скрипт
`python parse.py`
6. получить результат
результат последнего запуска - `output.csv`
архивные - в каталоге `/output` (создается автоматически)
вид `output.csv`
```csv
kadastral_number;object_type;is_active
11:22:0801002:400;Земельный участок;1
```
где
`object_type` - вид ОН
`is_active` - в Росреестре есть запись об ОН по кадастровому номеру
